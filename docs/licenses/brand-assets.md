# Official application artwork

Verified on 29 September 2026. Each bundled image is copied byte for byte from the
application’s own repository at the revision below. No image was traced, recolored,
redrawn, generated, optimized, or taken from a third-party icon collection. The
dashboard uses these independent assets only to identify the linked applications.

These files retain their own licenses. The MIT license for Homelab Dashboard’s
original application code does not relicense these images. GPL/AGPL/MPL/CC assets
are distributed as separate artwork alongside the original application; the original
SVG or PNG files and the retained license texts are included in the repository and
container image. Keep these notices and source files with redistributed copies.

Copyright licenses do not grant general trademark rights. Do not imply affiliation,
endorsement, or ownership of the application names or marks. This bundle is intended
for identifying the corresponding unmodified applications in a personal dashboard.

The exact paths, immutable source revisions, SHA-256 hashes and unchanged status are
also recorded in [brand-assets.json](brand-assets.json).

## Additional upstream notices

- **Jellyfin:** the original colored gradient is retained. The [official branding
  guidance](https://jellyfin.org/docs/general/contributing/branding/) prohibits using
  the Jellyfin mark as another project’s identity or implying affiliation. It is used
  here solely on the Jellyfin launcher tile. Artwork remains CC BY-SA 4.0.
- **Sonarr:** [the upstream copyright notice](sonarr-copyright.md) is retained in
  addition to the GPL text.
- **authentik:** this is the official orange icon from the pinned MIT-licensed
  `web/icons` source revision, before the upstream asset directory was reorganized.
  The [current press kit](https://goauthentik.io/press/) asks that color, proportions
  and spacing be preserved; this copy is unchanged.
- **FreshRSS:** the [official credits](https://freshrss.org/legal.html) name Cypouz and
  Vincent Lambert as logo designers. The square upstream icon is used unchanged.
- **Vaultwarden:** the SVG’s embedded credit names Mathijs van Veluw and identifies
  its relationship to the Rust logo. That pre-existing Vaultwarden adaptation is
  unchanged here. The Rust logo is owned by the Rust Foundation and is also covered
  by [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) under the
  [Rust art license and trademark policy](https://rustfoundation.org/policy/rust-trademark-policy/).
  Neither this dashboard nor Vaultwarden is presented as an official Rust product.
- **Syncthing:** its maintainer [confirms that the logo has the source-code license](https://forum.syncthing.net/t/using-syncthing-logo/21626/2)
  and permits use as-is for open-source integrations. The same post requests that
  commercial applications use their own branding. This project uses the mark only
  to identify Syncthing; commercial repackaging should remove it or obtain permission.

## Artwork intentionally not bundled

The frontend records the following IDs as unavailable and displays neutral initials.
It does not request old bundled artwork paths or fabricate replacement logos.

| Application    | Reason and authoritative source                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Grafana        | Its [trademark policy](https://grafana.com/trademark-policy/) prohibits marks in password-protected website areas and reserves other uses for separate permission. The former recolored Simple Icons SVG has been removed.                                                                                                                                                                                                        |
| Home Assistant | The [asset license](https://github.com/home-assistant/assets/blob/5d481bb46ffee92d17041701fcd826e4f662fe05/LICENSE.md) is CC BY-NC-SA 4.0; the [logo notice](https://github.com/home-assistant/assets/blob/5d481bb46ffee92d17041701fcd826e4f662fe05/logo/README.md) also restricts commercial use. No asset is bundled in this generally redistributable project.                                                                 |
| Nextcloud      | Its [REUSE manifest](https://github.com/nextcloud/server/blob/dd8f2f2680d2cd521ef72d8651b068d5bae964ea/REUSE.toml) assigns current logos `LicenseRef-NextcloudTrademarks`, not the server’s AGPL license. Its [trademark guidelines](https://nextcloud.com/trademarks/) permit identification of internal installations but do not provide a broad logo redistribution license for this illustrative catalog. No logo is bundled. |

This is a record of the project’s asset selection, not a representation that any
owner has granted an additional trademark license. Administrators can supply their
own appropriately licensed artwork for other applications using the catalog’s
`iconPath` setting. The known restricted IDs intentionally retain the initials
fallback in this distribution.
